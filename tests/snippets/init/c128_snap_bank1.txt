; c128_snap.vsf: VICE snapshot of a C128, RAM bank 1
; MMU configuration $00: the CPU is in RAM bank 0; this bank is read as all RAM
; RAM shared by the banks (RAM configuration $04): $0000-$0400, from bank 0
; CPU: PC $c262 A $00 X $0a Y $00 SP $f0 P $22
; stack $01f1-$0200: 00 08 94 b0 08 04 cf 02 f5 4a 4a 37 52 2c 40
; top of stack as a jsr return address: $0801
; top of stack as an interrupt's return address: $9408
; hardware vectors in RAM at $fffa: NMI $ff05 (RAM), reset $ff3d (RAM), IRQ $ff17 (RAM)
; video unknown: VIC-II 1.3 isn't read
; interrupt sources: none, unknown for VIC-II 1.3
deflower c128_snap.vsf $10000-$20000
$ff05 code hardware_nmi
$ff3d code reset
$ff17 code hardware_irq
$1300-$fee5 virtual byte untouched_1300
$ff45-$fff5 virtual byte untouched_ff45
include c128_zeropage.flo
vvv
